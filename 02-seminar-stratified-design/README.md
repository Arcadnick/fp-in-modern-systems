Автор: Орлов Алексей Олегович, ИВТ-14МО. Тема курса: «Неизменяемость и стратифицированный дизайн».
[Задание](https://lms.crafted.su/functional-programming-intro/2026-1-mag/docs/02-immutability-and-stratified-design/11-seminar-applying-stratified-design/):
построить граф вызовов своего приложения, выделить в нём слои и серией
изменений сделать слои явными, а затем сравнить графы до и после.

## Запуск

Нужен Python 3.10 или новее, внешних зависимостей нет.

```bash
cd 02-seminar-stratified-design
python3 -m filmoteka
```
