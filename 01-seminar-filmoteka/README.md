## Запуск

Нужен Python 3.10 или новее, внешних зависимостей нет.

```bash
cd 01-seminar-filmoteka
python3 -m filmoteka
```

Пункт меню **3** загружает тестовые данные. Те же данные лежат в `data/films.txt`:
их загружает пункт **1**.

## Проект

Консольный онлайн-кинотеатр: фильмы, мультфильмы и мультсериалы, зрители,
просмотры, оценки, рекомендации и статистика. Все данные хранятся в памяти.

**Откуда код.** Это лабораторная 2-го курса на C# (`Arcadnick/third_semester`,
`Lab 1-4`), перенесённая на Python в том же ООП-стиле. Для требований семинара
(не меньше 3 сущностей и 10 операций) к ней добавлены зритель и каталог.

**Сущности**

| Класс | Что хранит |
|---|---|
| `Cinematography` → `Film`, `Cartoon` → `Serial` | название, режиссёр, жанр, год, рейтинг, просмотры, оценки; у наследников — бюджет, персонажи, серии и сезоны |
| `Playlist` | упорядоченный список произведений |
| `Viewer` | любимые жанры, история просмотров, оценки, личный плейлист |
| `Catalog` | общий плейлист и зрители |

Связи: `Catalog` 1—1 `Playlist` 1—N `Cinematography`; `Catalog` 1—N `Viewer`;
`Viewer` N—M `Cinematography` (история, оценки, плейлист).

**Операции (меню):** загрузка и сохранение файла, тестовые данные, вывод,
подъём рейтинга, сравнение двух фильмов, сортировка по названию и по рейтингу,
фильтр по жанру и типу, удаление дубликатов, регистрация зрителя, просмотр,
оценка, личный плейлист, профиль, рекомендации, статистика каталога
и (с этапа 4) отмена последнего изменения. Всего 18 пунктов.

## Исходное состояние

Коммит `eb89b78`. Классический ООП с изменяемым состоянием. Недостатки
оставлены намеренно, потому что их и предстояло исправить:

| Метод | Неявные входы | Неявные выходы |
|---|---|---|
| сеттеры свойств | — | печать ошибки, тихая подстановка значения |
| `Viewer.watch(film)` | — | `film.views += 1`, печать |
| `Viewer.rate(film, score)` | `self.ratings` | `film.votes`, `film.rating`, печать |
| `Catalog.print_statistics()` | `self.films` | печать |
| `Playlist.sort_by_*()` | `self.cinema` | список переставлен на месте |
| функции меню | глобальный `catalog`, `input()` | печать, `global catalog = …` |
| исключения | — | печать в конструкторе |

## Этапы рефакторинга

После каждого этапа один и тот же сценарий прогонялся по всем пунктам меню,
и вывод сравнивался с предыдущим этапом.

| Коммит | Этап | Что сделано |
|---|---|---|
| `1449e94` | 1. Выделение вычислений | Расчёты вынесены в чистые функции `calculations.py`: проверки, рейтинг по оценкам, рекомендации, статистика, дубликаты. Вывод программы не изменился ни на символ |
| `1b7b32f` | 2. Структура действий | Глобального `catalog` нет: каждое действие меню получает каталог аргументом и возвращает его. Модели и исключения не печатают, а возвращают значения или бросают ошибку с текстом. Весь ввод-вывод — в `main.py` |
| `a7de562` | 3. Конструкторы и обобщение | `constructors.py`: таблица `MAKERS` вместо цепочки `if`, `parse_playlist`, `make_test_catalog`. Файлы — в `storage.py`. Обобщённые `find_first`, `sorted_by`, `group_by`, `checked` + `one_of`, `with_viewer`, `with_viewer_and_film` |
| `cb9a9b1` | 4. Copy-on-write | Объекты не меняются: `with_view`, `with_vote`, `with_raised_rating`, `Catalog.watch` и другие возвращают копии через `copy_with`. Зритель хранит названия фильмов. Добавлен пункт «Отменить последнее изменение» |

Посмотреть изменения этапа: `git show <коммит>`. Сравнить начало и конец:
`git diff eb89b78 cb9a9b1`. Этапы делались, пока проект лежал в корне
репозитория, поэтому в этих коммитах пути без `01-seminar-filmoteka/`.

## Итоговая структура

| Категория | Где | Примеры |
|---|---|---|
| **Данные** | `cinematography.py`, `playlist.py`, `viewer.py`, `catalog.py` | после создания не меняются; изменения — через копии |
| **Вычисления: общие** | `calculations.py` | `copy_with`, `find_first`, `sorted_by`, `group_by`, `replaced`, `one_of`, `average`, `item_at` |
| **Вычисления: предметная область** | `calculations.py`, методы классов | `rating_from_votes`, `recommendations`, `average_rating_by_genre`, `top_by_rating`, `most_viewed`, `with_vote`, `Catalog.watch` |
| **Бизнес-правила** | `calculations.py` | `is_valid_year`, `is_valid_rating`, `can_raise_rating`, `has_favorite_genre` |
| **Конструкторы** | `constructors.py` | `make_film`, `parse_cinematography`, `parse_playlist`, `make_test_catalog` |
| **Действия** | `main.py`, `storage.py` | `input()`, `print()`, файлы, журнал ошибок, история для отмены |

Действия остались только на краях программы. Всё остальное проверяется
простым вызовом функции, без консоли и файлов.
