# Фильмотека

Учебный проект для семинара «Применение базовых техник улучшения кода»
(курс «Технологии функционального программирования в современных ИС»).

Консольное приложение для каталога фильмов, мультфильмов и мультсериалов
со зрителями, оценками и рекомендациями. Все данные хранятся в памяти,
файл используется только для загрузки и сохранения списка.

## Откуда код

Это перенос на Python лабораторной работы 2-го курса на C#
(`Arcadnick/third_semester`, `Lab 1-4/Lab_1`). Классы, свойства с валидацией,
исключения и меню перенесены по смыслу один к одному. Для требований семинара
(не меньше 3 сущностей и 10 операций) добавлены зритель (`Viewer`) и онлайн-кинотеатр
(`Catalog`), написанные в том же стиле.

Первый коммит — **исходное состояние**: классический ООП с изменяемым состоянием.
Следующие коммиты — этапы рефакторинга (см. «История изменений»).

## Запуск

Нужен Python 3.10 или новее, внешних зависимостей нет.

```bash
python3 -m filmoteka
```

Тестовые данные загружаются пунктом 3 меню. Те же данные лежат в файле
`data/films.txt` (пункт 1).

## Сущности

| Сущность | Файл | Что хранит |
|---|---|---|
| `Cinematography` → `Film`, `Cartoon` → `Serial` | `filmoteka/cinematography.py` | название, режиссёр, жанр, год, рейтинг, просмотры, оценки; у наследников — бюджет, персонажи, серии и сезоны |
| `Playlist` | `filmoteka/playlist.py` | упорядоченный список произведений |
| `Viewer` | `filmoteka/viewer.py` | любимые жанры, история просмотров, оценки, личный плейлист |
| `Catalog` | `filmoteka/catalog.py` | общий плейлист и зарегистрированные зрители |

Вспомогательные модули (появились при рефакторинге): `calculations.py` —
чистые функции, `constructors.py` — сборка объектов, `storage.py` — файлы,
`main.py` — меню, единственное место с вводом-выводом.

Связи: `Catalog` 1 — 1 `Playlist` 1 — N `Cinematography`; `Catalog` 1 — N `Viewer`;
`Viewer` N — M `Cinematography` (через историю, оценки и личный плейлист).

## Операции (пункты меню)

1. Загрузить данные из файла
2. Сохранить данные в файл
3. Загрузить тестовые данные
4. Вывести данные на экран
5. Поднять рейтинг фильму на 1
6. Сравнить два фильма
7. Сортировка по названию
8. Сортировка по рейтингу
9. Фильтр по жанру или типу
10. Удалить дубликаты
11. Зарегистрировать зрителя
12. Зритель смотрит фильм (история и счётчик просмотров)
13. Зритель ставит оценку (рейтинг пересчитывается как среднее)
14. Добавить фильм в плейлист зрителя
15. Профиль зрителя
16. Рекомендации зрителю (любимые жанры, не просмотрено, по рейтингу)
17. Статистика каталога (средний рейтинг по жанрам, топ, просмотры)
18. Отменить последнее изменение (появилось на этапе 4)

## История изменений

Каждый этап — отдельный коммит. Посмотреть, что изменилось на этапе:
`git show <коммит>`. Вернуться к любому состоянию: `git checkout <коммит>`.

| Этап | Коммит | Что сделано |
|---|---|---|
| Исходное состояние | `Исходное состояние: фильмотека…` | перенос C# → Python, классический ООП |
| 1. Выделение вычислений | `Этап 1: выделение вычислений из действий` | расчёты вынесены в чистые функции `calculations.py`, поведение не изменилось |
| 2. Структура действий | `Этап 2: улучшение структуры действий` | нет глобальной переменной, каталог передаётся аргументом; классы и исключения не печатают, а возвращают значения; весь ввод-вывод — в `main.py` |
| 3. Конструкторы и обобщение | `Этап 3: выделение конструкторов и обобщение` | `constructors.py` (таблица `MAKERS` вместо цепочки `if`), `storage.py`; обобщённые `find_first`, `sorted_by`, `group_by`, `checked`, `one_of`, `with_viewer`, `with_viewer_and_film` |
| 4. Copy-on-write | `Этап 4: copy-on-write` | объекты не меняются, операции возвращают копии (`copy_with`); пункт меню «Отменить последнее изменение» |

## Итоговая структура: функции по категориям

| Категория | Где | Примеры |
|---|---|---|
| **Данные** | `Cinematography`, `Film`, `Cartoon`, `Serial`, `Playlist`, `Viewer`, `Catalog` | неизменяемые после создания; изменения — через копии |
| **Вычисления: общие (не знают о фильмах)** | `calculations.py` | `copy_with`, `find_first`, `sorted_by`, `group_by`, `replaced`, `one_of`, `average`, `item_at`, `same_text` |
| **Вычисления: предметная область** | `calculations.py`, методы классов | `rating_from_votes`, `better_of`, `recommendations`, `average_rating_by_genre`, `top_by_rating`, `most_viewed`, `unique_by_line`, `with_vote`, `with_view`, `Catalog.watch` |
| **Бизнес-правила** | `calculations.py` | `is_valid_year`, `is_valid_rating`, `is_positive`, `can_raise_rating`, `has_favorite_genre` |
| **Конструкторы** | `constructors.py` | `make_film`, `make_cartoon`, `make_serial`, `parse_cinematography`, `parse_playlist`, `make_test_catalog` |
| **Действия** | `storage.py`, `main.py` | чтение и запись файла, `input()`, `print()`, журнал ошибок, история для отмены |

Действия остались только на краях программы: меню читает ввод, вызывает
вычисления и печатает результат. Всё, что между, можно проверить без консоли
и файлов, просто вызвав функцию.

## Проблемы исходного состояния

Что было в первом коммите (оставлено намеренно, исправлено на этапах 1–4):

- **Неявные выходы.** Сеттеры свойств печатают ошибки в консоль, исключения печатают
  подсказку прямо в конструкторе, `raise_rating`, `watch`, `rate`, `load_from_file`
  сами пишут результат на экран.
- **Неявные входы.** Функции меню читают глобальную переменную `catalog`.
- **Изменение данных на месте.** `sort_by_name` и `sort_by_rating` переставляют внутренний
  список плейлиста, `raise_rating` и `rate` меняют рейтинг произведения,
  `watch` увеличивает его счётчик просмотров, `get_all` отдаёт наружу внутренний список.
- **Вычисления, смешанные с действиями.** Подсчёт статистики, рекомендаций
  и среднего рейтинга неотделим от печати и изменения объектов.
- **Повторяющийся код.** Валидация в каждом сеттере, разбор строк файла через цепочку
  `if` по типу, похожие функции выбора в меню.
