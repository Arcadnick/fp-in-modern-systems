# Технологии функционального программирования в современных ИС

Репозиторий с работами по курсу. Магистратура, 2026/27 учебный год.

Автор: Орлов Алексей Олегович, группа ИВТ-14МО.

- Материалы курса: <https://lms.crafted.su/functional-programming-intro/2026-1-mag/>
- Каждая работа — в своей папке с собственным README.
- Если не сказано иное, код на Python 3.10+ без внешних зависимостей.
- Диаграммы собираются Graphviz (`dot`), их исходники лежат рядом с SVG.

## Работы

| № | Папка | Тема курса | Что сделано |
|---|---|---|---|
| 1 | [`01-seminar-filmoteka`](01-seminar-filmoteka/) | Действия, вычисления и данные — семинар «Применение базовых техник улучшения кода» | Консольная фильмотека: из ООП-кода выделены вычисления, улучшена структура действий, введён copy-on-write. Есть презентация и текст доклада |
| 2 | [`02-seminar-stratified-design`](02-seminar-stratified-design/) | Неизменяемость и стратифицированный дизайн — семинар «Применение стратифицированного дизайна» | Та же фильмотека: граф вызовов строится скриптом по коду, семь изменений по четырём шаблонам, сравнение графов до и после. Есть презентация (PDF и HTML) и текст доклада |

## Как устроен репозиторий

```
fp-in-modern-systems/
├── README.md               ← этот файл
├── .gitignore              ← общий для всех работ
├── 01-seminar-filmoteka/   ← работа 1
│   ├── README.md
│   ├── filmoteka/          ← код
│   ├── data/               ← тестовые данные
│   └── presentation/       ← слайды и текст доклада
└── 02-seminar-stratified-design/   ← работа 2
    ├── README.md
    ├── filmoteka/          ← код
    ├── data/
    ├── diagrams/           ← графы вызовов, схемы данных, скрипт и метрики
    └── presentation/
```

Новая работа — новая папка с номером (`02-…`, `03-…`) и строка в таблице выше.
